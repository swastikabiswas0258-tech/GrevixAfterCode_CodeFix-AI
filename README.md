# GrevixAfterCode_CodeFix-AI
⚡ CodeFix AI – Code Error Assistant
Find Bugs. Understand Errors. Write Better Code.

📌 About the Project
CodeFix AI is a beginner-friendly web application designed to help programmers identify common coding errors and understand Python syntax problems.

The application analyzes submitted code and provides simple explanations and suggestions to help users debug their programs.

✨ Features
Python syntax error detection
Basic undefined-variable checks
Error explanations and debugging suggestions
Simple and user-friendly interface
Code analysis through a Flask backend
Dark-themed web interface
🛠️ Technologies Used
Python
Flask
HTML
CSS
JavaScript

⚙️ Installation
1. Clone the repository
git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder
cd CodeFix-AI

3. Install dependencies
python -m pip install -r requirements.txt

4. Run the application
python app.py

5. Open in your browser
http://127.0.0.1:5000

⚠️ Current Limitations
Advanced AI-powered explanations are not yet enabled.
Code analysis currently focuses on Python.
Static checks cannot detect every logical or runtime error.
Other programming languages are not fully supported yet.
